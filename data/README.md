# 데이터

## 정책

유튜브 댓글 원문은 이 저장소에 넣지 않는다. 저작권과 플랫폼 약관 때문이다. 실데이터는 `data/real/`에 두며 이 경로는 `.gitignore`에 있다. 공개하는 것은 스키마와 집계 통계, 평가 결과뿐이다.

이 폴더의 `sample_*.csv`는 형식을 보여주기 위한 합성 데이터이며 실제 댓글이 아니다.

## 스키마

정답 파일과 예측 파일을 나눈다. `id`로 맞춘다.

**정답(골든셋) — `*_comments.csv`**

| 열 | 설명 |
| --- | --- |
| `id` | 댓글 식별자 |
| `text` | 댓글 본문 |
| `label` | `긍정` \| `부정` \| `복합` |

**예측 — `*_predictions.csv`**

| 열 | 설명 |
| --- | --- |
| `id` | 정답 파일과 동일한 식별자 |
| `label` | 모델이 예측한 라벨 |

두 파일을 분리해 두는 이유가 있다. 정답과 예측이 한 파일에 있으면 평가 스크립트가 정답 열을 볼 수 있고, 그러면 언젠가 실수로 그걸 쓰게 된다.

## 골든셋을 만들 때

목표는 **200건**이다. 시작하기 전에 [../docs/labeling-guide.md](../docs/labeling-guide.md)를 먼저 읽는다. 기준 없이 매기기 시작하면 앞부분과 뒷부분의 기준이 달라지고, 그 골든셋은 못 쓴다.

여러 영상과 여러 언어에서 고르게 뽑는다. 한 영상에 몰리면 그 영상의 특성을 평가하는 셈이 된다.

라벨링 대상에서 제외한 댓글은 건수와 사유를 기록한다(가이드 규칙 1). 제외율은 버리는 정보가 아니라 수집 품질을 보여주는 지표다.

완성한 뒤에는 학습이나 프롬프트 튜닝에 **한 번도 쓰지 않는다.** 한 번 섞이면 되돌릴 수 없다.
