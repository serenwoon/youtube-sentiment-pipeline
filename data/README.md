# 데이터

## 정책

유튜브 댓글 **원문은 이 저장소에 포함하지 않는다** (저작권·플랫폼 약관). 실데이터는 `data/real/`(gitignore됨)에 로컬로만 둔다. 공개하는 것은 스키마, 집계 통계, 평가 결과뿐이다.

이 폴더의 `sample_*.csv`는 형식 시연용 **합성 데이터**다 — 실제 댓글이 아니다.

## 스키마

### 정답(골든셋) 파일 — `*_comments.csv`

| 열 | 설명 |
|---|---|
| `id` | 댓글 식별자 |
| `text` | 댓글 본문 (합성) |
| `label` | `긍정` \| `부정` \| `복합` |

### 예측 파일 — `*_predictions.csv`

| 열 | 설명 |
|---|---|
| `id` | 정답 파일과 동일한 식별자 |
| `label` | 모델이 예측한 라벨 |

## 골든셋 만들 때

- 목표 **200건**. 라벨링 기준은 [../docs/labeling-guide.md](../docs/labeling-guide.md)를 **먼저 읽고 시작한다**
- 여러 영상·여러 언어에서 고르게 뽑는다. 한 영상에 몰리면 그 영상의 특성을 평가하는 셈이 된다
- 라벨링 대상에서 제외한 댓글의 **건수와 사유**를 기록한다 (가이드 규칙 1)
- 완성 후 학습·프롬프트 튜닝에 **한 번도 쓰지 않는다.** 한 번 섞이면 되돌릴 수 없다
