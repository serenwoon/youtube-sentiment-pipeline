# 데이터

댓글 원문은 커밋하지 않는다. 저작권과 플랫폼 약관 때문이다. 실데이터는 `data/real/`에 두고 이 경로는 gitignore에 있다.

`sample_*.csv`는 형식 확인용 합성 데이터다. 실제 댓글이 아니다.

## 스키마

정답과 예측을 다른 파일로 둔다. `id`로 맞춘다.

`*_comments.csv`

| 열 | 설명 |
| --- | --- |
| `id` | 댓글 식별자 |
| `text` | 댓글 본문 |
| `label` | `긍정` \| `부정` \| `복합` |

`*_predictions.csv`

| 열 | 설명 |
| --- | --- |
| `id` | 정답 파일과 같은 식별자 |
| `label` | 예측 라벨 |

한 파일에 두면 분류기 쪽에서 정답 열이 보이고, 언젠가 실수로 쓰게 된다.

## 골든셋 만들 때

목표 200건. 시작 전에 [../docs/labeling-guide.md](../docs/labeling-guide.md)를 읽는다. 기준 없이 매기면 앞부분과 뒷부분 기준이 달라져서 쓸 수 없게 된다.

여러 영상, 여러 언어에서 고르게 뽑는다. 한 영상에 몰리면 그 영상을 평가하는 셈이 된다.

제외한 댓글은 건수와 사유를 적어둔다(가이드 규칙 1).

다 만든 뒤에는 학습이나 프롬프트 튜닝에 쓰지 않는다.
